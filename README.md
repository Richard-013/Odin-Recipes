# Odin-Recipes

Repo for the Recipes task from The Odin Project

Skills:

- HTML
- Git
- GitHub
- Linux
- WSL

Task:

Create a basic HTML only website that showcases a collection of recipes on separate pages with navigation links between the pages. Use Git and GitHub to manage the version control and repo. Use the Linux Terminal to interact with Git and handle file creation.

Sources:

- Example Content: [All Recipes](https://www.allrecipes.com/)
- Project Guidance: [The Odin Project: Recipes Project](https://www.theodinproject.com/lessons/foundations-recipes)
